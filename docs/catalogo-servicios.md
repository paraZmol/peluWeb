# Catálogo de servicios — semilla (116 servicios, investigado 2026-10-04)

Sirve para dos cosas:
1. Los **salones parten de una plantilla** según su tipo (barbería, salón de belleza, unisex, uñas,
   spa) en vez de cargar todo a mano.
2. Los **clientes encuentran un estilo concreto** ("quiero un mid fade", "wolf cut").

**Convenciones**
- **Dur.**: duración total típica en minutos.
- **A / E / F**: minutos **A**ctivos / de **E**spera, cuando el profesional queda libre / **F**inales
  activos. "—" significa que todo el servicio es activo.
- **Target**: H = hombre, M = mujer, U = unisex, N = niños.
- **PEN (est.)**: rango **estimado** para Lima, gama media. Los locales de barrio cobran menos;
  Miraflores, San Isidro y Surco cobran entre 1.5 y 2 veces más.
- "+ largo": recargo del 20–50 % para cabello largo o extra largo.
- Duraciones y precios son **referencias editables**: cada salón y cada profesional fija los suyos.
  Uñas, depilación, maquillaje, masajes, alisado japonés, airtouch y corrección de color son
  extrapolaciones y deben validarse con salones reales.

| `requires_evaluation` | true/false: el precio se confirma en el salón (corrección, fantasía, alisados) |

| `active / idle / finish` | minutos de cada tramo para la agenda (ver skill `booking-domain`) |

**Notas para el modelo de datos**
- Guardar cada servicio en tres tramos (activo → espera → final), para que durante la espera de
  un color quepa un corte de 30 minutos de otra persona.
- Los servicios "+ largo" se modelan con **variantes** por largo de cabello.
- **Combos frecuentes:** corte + barba · corte + lavado · tinte + matiz · balayage + matiz + brushing ·
  mani + pedi · lifting + laminado.
- Indexar el nombre en inglés como **sinónimo** de búsqueda ("fade", "balayage", "wolf cut", "lash lift").
- **Plantillas por tipo de salón:** Barbería = CH + BA + IN01/IN03 + CO03 · Salón de belleza = CM +
  CO + TQ + PE + IN02 · Unisex = las dos anteriores · Uñas = UN + CP · Spa/estética = ES + DE + CP + UN07.
- **Galería de estilos:** cada estilo de corte (CH, CM, IN) lleva una foto de referencia para que
  el cliente señale "quiero esto". En v1 la foto la sube cada salón; no se usan imágenes de terceros.

Fuentes de precios: Fresha Lima (barberías, cortes, barba, balayage), LimaSabe, Heavenly Spa Lima,
Soho Color, Cuponidad, Lovely Lashes Perú.
